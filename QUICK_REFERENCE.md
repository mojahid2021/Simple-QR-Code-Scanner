# Quick Reference Guide - QR Scanner Pro

## 🚀 Quick Start

### First Launch
1. Grant camera permission when prompted
2. Point camera at any QR code
3. App automatically scans and processes

## 📱 Main Features

### Standard Scanning
- **Open app** → Camera starts automatically
- **Point at QR code** → Automatic detection
- **View result** → Data copied to clipboard
- **Rescan** → Tap "Rescan" button

### Batch Scanning
- **Tap "Batch Scan Mode"** from main screen
- **Scan multiple codes** → Each unique code added to list
- **Tap any code** → Copy to clipboard
- **Save All** → Store all codes in history
- **Clear All** → Start fresh

### Scan from Image
- **Tap "From Image"** from main screen
- **Select image** from gallery
- **View result** → Detected QR code displayed
- **Process** → Works with screenshots and photos

### Generate QR Codes
- **Tap "Generate"** from main screen
- **Select type** → Text, URL, WiFi, Contact, Email, Phone
- **Fill details** → Type-specific fields appear
- **Generate** → QR code created instantly
- **Save** → Stored in Pictures/QRCodes folder

## ⚡ Tips & Tricks

### For Best Results
- Hold device steady
- Ensure good lighting
- Keep QR code in frame
- Clean camera lens
- Avoid reflections

### Scanning Difficult Codes
- Use flashlight in low light
- Zoom by moving closer
- Try different angles
- Use "From Image" feature for screenshots

### Batch Scanning
- Scan quickly, app handles duplicates
- Watch the count increase
- Review list anytime
- Save when done

### Generating QR Codes
- Use WiFi type for easy sharing
- URL type for website shortcuts
- Contact type for business cards
- Text type for notes

## 🆘 Troubleshooting

### Camera Not Working
1. Check permissions in Settings
2. Restart app
3. Restart device
4. Reinstall app

### Can't Scan QR Code
1. Clean camera lens
2. Improve lighting
3. Hold steady
4. Try "From Image" mode

### History Not Saving
1. Check storage permissions
2. Clear app cache
3. Restart app

### Export Not Working
1. Check storage permissions
2. Ensure sufficient space
3. Try alternative export format
